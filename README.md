# FlowHint – LinkedIn Automation legal website

Static site with Privacy Policy, Terms of Service and Contact (governed by Nigerian law).

## Preview
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and `styles.css`.
3. Settings > Pages > Deploy from a branch > `main` / root > Save.
4. Use the generated URL as your Privacy Policy / Terms URL in the LinkedIn Developer portal.

Have the documents reviewed by a Nigerian lawyer and confirm they match how the app actually stores tokens and handles deletion. This is not legal advice.
